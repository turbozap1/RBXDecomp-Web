Roblox engine in your browser

Original C++ engine and OpenGL rendering source compiled to WebAssembly.

RbxView → RenderLib → GLG3D → Mesa 6.5 runs inside WASM, including meshes, materials, textures and game UI. The page presents the C++ framebuffer. This port is still incomplete; the Windows editor shell and Ogre renderer are not ported.

Roblox Lua

Scripts use the original game, workspace, Instance, Vector3, and service bindings. Run the demo, then start the simulation to watch its Parts fall and collide.

Compatible game server

Start the included server with python web/serve.py --game-server, then join below. The original NetworkClient and RakNet replicate the server's world and spawn the original character. This targets the 2007 protocol.

Sound

Enable audio, choose a sound file, then run the generated script. This creates an actual Roblox Sound instance connected to the Web Audio backend.
