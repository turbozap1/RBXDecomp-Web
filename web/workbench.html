RBXDecomp / WebAssemblyLoading…

Browser platform workbench

Original Roblox Lua 5.1.1 compiled to WebAssembly, with browser networking and audio adapters.

This build does not yet run the Roblox engine or join games. Rendering, physics, Roblox script bindings, and replication are not connected.

Network transport

Connects to a WebSocket endpoint or the supplied UDP gateway. This tests transport, without performing a RakNet handshake or a game join.

Audio

Enable audio, then choose a local browser-supported sound file to generate a Lua playback script.
